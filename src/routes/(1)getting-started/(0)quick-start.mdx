Install Node.js `20.19` or later, or `22.12` or later.
These versions satisfy the Vite 8 runtime requirement used by the maintained templates.

Run the Solid CLI:

```bash
npm init solid@latest
```

Use the equivalent command for another package manager:

```bash
pnpm create solid@latest
yarn create solid@latest
bun create solid@latest
```

Choose the `basic` project shape when the CLI prompts you.
Choose a project directory and package manager, then run the development command printed by the CLI.

Open the local URL printed by the development server to see your app.

The `basic` project includes:

- A router with file-system routes.
- Per-page titles.
- A test suite.
- A purely static production build.

The source template has no hand-written `index.html` or mount file.
The Vite plugin's start mode generates the entries around two files:

- `src/App.tsx` is the app, router included.
- `src/Document.tsx` is the document shell. Site-wide head tags go here.

The static production build emits `dist/client/index.html`.

Edit files under `src/routes` and the route table follows.

## Other project shapes

The CLI offers three project shapes, each a superset of the last.
Pick the one that matches what you are building, or read about [project shapes](/getting-started/project-shapes) to compare them.

- `bare`: no router, pure static output.
- `basic`: router, file-system routes, testing. Still pure static.
- `fullstack`: streaming SSR with server functions, sessions, and API routes.
