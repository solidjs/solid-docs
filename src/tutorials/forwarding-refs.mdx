# Forwarding refs

A wrapper component can forward a ref prop to its underlying native element:

```jsx
function Canvas(props) {
  return <canvas ref={props.ref} width="256" height="256" />;
}
```

The parent captures that native canvas and manages its external animation in its own `onSettled` callback. The wrapper only forwards the ref; it does not create a second lifecycle.

**Try it:** forward `props.ref` from `Canvas` to the native canvas. The parent's existing draw loop should start working. Its returned cleanup cancels the loop when the parent is disposed.
