# Reactive styles

The `style` prop accepts a string or an object of CSS properties. Reads inside that object remain reactive.

```jsx
<div style={{ color: `rgb(${num()}, 180, ${num()})`, 'font-size': `${num()}px` }} />
```

Use CSS property spelling for hyphenated names. DOM updates follow the individual bindings rather than rerunning the component setup. The exercise's timer is owned through `onSettled` and returns cleanup.

**Try it:** make the text's color, weight, and font size depend on `num()`. Keep the source changes in the timer callback and the visual derivations in JSX.
