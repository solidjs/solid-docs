# DOM work after rendering

A ref captures an element while the view is being created. `onSettled` runs owned setup work after rendering has settled, when an ordinary mounted element is available for DOM integration.

```js
let input;
onSettled(() => input.focus());
```

Use this for focus, layout measurement, or attaching external listeners. It is not the usual place to fetch application data and copy the result into signals; async derivations handle that later in the course.

**Try it:** focus the input from `onSettled`. Reset the preview and check that the input receives focus after each mount. The callback may also return cleanup, which the next lesson uses.
