# Choosing a branch

`Switch` selects the first matching `Match`. Each condition is a reactive expression, and `fallback` handles the case where none match.

```jsx
<Switch fallback={<p>Small number</p>}>
  <Match when={x() > 10}>
    <p>Over ten</p>
  </Match>
  <Match when={x() > 5}>
    <p>Over five</p>
  </Match>
</Switch>
```

Order matters: a more general condition placed first can hide a later branch. Only the selected branch owns live work.

**Try it:** replace the nested conditional in the editor with `Switch` and `Match`. Preserve its thresholds and messages, then edit the signal's initial value to exercise each branch.
