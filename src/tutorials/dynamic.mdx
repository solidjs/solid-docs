# Dynamic components

When a reactive value selects a component, use the `dynamic` factory from `@solidjs/web`:

```js
const Selected = dynamic(() => options[selected()]);
```

Create the factory once in the component body, then render `<Selected />` like any other component. Its source tracks which component to instantiate. Props and children follow the normal JSX path.

**Try it:** replace the fixed `<RedThing />` with a dynamic component selected by the dropdown. Choosing green or blue should change the component. Keep the factory outside JSX so its identity remains stable.
