# Derived values

A value that can be calculated from another value usually needs no setter. A getter function expresses that relationship:

```js
const doubleCount = () => count() * 2;
```

When JSX calls `doubleCount()`, the underlying read of `count()` becomes a dependency of that binding. As `count` changes, Solid reevaluates the expression. There is no second signal to keep synchronized, and no effect that writes the result back.

**Try it:** add `doubleCount` and display its result. The button already updates the source. Changing the derivation changes what the interface shows without changing how the source is written.
