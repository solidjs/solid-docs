# Writable derived state

Some state has a default that depends on another source, while the user must also be able to edit it. A function-form signal expresses both requirements:

```js
const [draft, setDraft] = createSignal(() => names[person()]);
```

Changing the person recomputes the draft's default. Typing updates the writable draft until its source changes again. This is a derivation with an override, so no effect is needed to copy values between signals.

**Try it:** change the draft's literal initializer to a function that reads the selected person's name. Type a custom name, then choose another person. The draft should reset to that person's default. **Solve** shows the complete relationship.
