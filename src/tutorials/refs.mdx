# Capturing DOM elements

A ref gives imperative code access to a real DOM element. An assignment ref is concise:

```jsx
<canvas ref={canvas} width="256" height="256" />
```

Capture the element in the view, then start its animation loop in `onSettled`. Return cleanup to cancel the final scheduled frame. Plain ref callbacks run without an owner, so creating effects or registering cleanup inside them is not valid setup.

**Try it:** attach the canvas ref so the existing animation can obtain its drawing context. The loop should stop when the preview is reset or its component is removed.
