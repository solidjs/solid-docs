# Portals

`Portal` renders its children into another DOM container, while those children keep their place in Solid's ownership and context graph. This is useful for dialogs and overlays that must escape an ancestor's clipping or stacking context.

```jsx
<Portal mount={document.body}>
  <div class="popup">An overlay</div>
</Portal>
```

The DOM location changes; the component lifetime and provided context still follow the app that created the portal. Removing the owning branch removes the portal's content too.

**Try it:** wrap the popup with `Portal` so its position is no longer constrained by the clipped container. Import `Portal` from `@solidjs/web`.
