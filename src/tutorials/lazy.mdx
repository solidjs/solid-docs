# Loading component code

`lazy` turns a dynamic module import into a component factory. Create it once at module scope or in an owning setup scope, then render it normally.

```js
const Greeting = lazy(() => import('./greeting'));
```

Its code becomes another async dependency of the rendering graph. Put the lazy component under `Loading` to give that wait a fallback. Bundlers can split dynamic imports into separate chunks; no application signal is needed to copy the imported component into state.

**Try it:** replace the direct greeting import with `lazy`. Keep the artificial delay if you want to see the fallback. This changes when code is loaded, while the component's props and owned lifetime follow the usual rules.
