Async computation outside Loading boundary (non-halting; root mount is deferred).

## Why it fires

On the client, an async value was read outside a Loading boundary during mounting.
The root mount waits until the pending async work settles.

## How to fix it

Put the pending content inside `<Loading>` and provide a fallback if the page should show something while it waits.

During SSR, reading a source declared with `ssrSource: "client"` outside `<Loading>` throws an error because the server cannot run that source.
Wrap the read in `<Loading>` to provide a fallback, or declare `loadingValue`/`seedLoadingValue` to render a provisional value.
