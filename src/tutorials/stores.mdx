# Stores and nested reads

A signal tracks one value. A store tracks reads of nested object and array properties. Import `createStore` directly from `solid-js`.

```js
const [todos, setTodos] = createStore([]);
setTodos((draft) => {
  draft.push({ id: 1, text: 'Learn stores', completed: false });
});
```

Store readers use properties rather than calling a getter. Write through the setter's mutable draft. Outside that callback, treat the store as read-only.

**Try it:** find the todo with the requested ID in the draft and toggle its `completed` field. Add a todo and check its checkbox. The checkbox and text decoration should update without replacing the todo object or building a signal for each field.
