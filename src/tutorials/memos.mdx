# Cached derivations

A plain derived function runs each time you call it. A memo owns a cached answer and tracks the sources used to compute that answer.

```js
const fib = createMemo(() => fibonacci(count()));
```

All readers share the memo's result. A change to `count` invalidates it; unrelated changes do not. The computation must describe a value, so keep logging, DOM mutation, network writes, and signal setters out of its compute function.

**Try it:** replace the repeated Fibonacci function calls with a memo named `fib`. Read `fib()` at every display location. The calculation is shared across those bindings. Later, the same `createMemo` shape will derive answers from promises.
