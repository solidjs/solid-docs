# Signals

A signal is a writable source. `createSignal(0)` returns a getter and setter. Calling the getter in JSX subscribes that binding to the source; calling it in an event handler simply reads the current value.

```js
const [count, setCount] = createSignal(0);
setCount((value) => value + 1);
```

The updater receives the latest staged value, so several increments in one event compose correctly. Updates become visible after Solid's microtask batch commits. We will examine that timing shortly.

**Try it:** create `count`, display `count()` instead of the literal `0`, and increment it from the button's click handler. Keep the changing read in JSX; copying `count()` into a plain setup variable would only capture a snapshot.
