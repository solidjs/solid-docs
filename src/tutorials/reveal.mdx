# Coordinating reveal order

Several independent async regions can load together while revealing in a deliberate order. Give each region a `Loading` boundary, then group them with `Reveal`.

```jsx
<Reveal order="sequential" collapsed>
  <Loading fallback={<p>Loading profile...</p>}>
    <Profile />
  </Loading>
  <Loading fallback={<p>Loading posts...</p>}>
    <Posts />
  </Loading>
</Reveal>
```

`sequential` reveals siblings in order. `together` waits for the group. `natural` lets each region reveal as it becomes ready. `collapsed` is a sequential-only option that limits later fallback displays.

**Try it:** wrap the profile sections in `Reveal order="sequential" collapsed`. Keep all three sections behind their own `Loading` boundaries. Compare sequential behavior with `order="together"`; the requests remain independent even when the UI waits to reveal them together.
