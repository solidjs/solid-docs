`refresh()` target is not a source accessor or refreshable store.

## What you saw

- **Kind:** `write`
- **Severity:** `error` (broken behavior)

The console report opens with `[INVALID_REFRESH_TARGET]` and the message, then an `in` line naming the owners that enclose the subject, root first, and an `at` line with the source location when the code was compiled with one.
In a captured artifact the same finding is an event with `code: "INVALID_REFRESH_TARGET"`, `ownerPath`, and `loc`.
[Diagnostics](/reference/solid-js/diagnostics#read-a-report) explains each line.

## Why it fires

`refresh()` expects a Solid source accessor or refreshable store — not a wrapper function or a derived property read.

## How to fix it

Pass the original source.

## In tests

`captureArtifact` from `@solidjs/diagnostics` runs a scenario with the diagnostics channel open and returns the events it saw.
`expectNoDiagnostics(artifact)` fails while `INVALID_REFRESH_TARGET` is among them, with the events as evidence; after the fix, the code is gone from `artifact.diagnostics`.
