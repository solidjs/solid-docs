# Your first Solid 2 app

Solid connects changing values to the parts of an interface that read them. A component creates that reactive graph once. Updates then run the affected computations and DOM bindings; they do not rerun the whole component function.

The editor contains an app you can change. `render` from `@solidjs/web` creates a root in the preview's `app` element. Core state APIs come from `solid-js`. These lessons target Solid **2.0.0-rc.18**.

**Try it:** change the greeting to `Hello Solid World!`, then use **Solve** to compare your answer. **Reset** returns to the starter. Later lessons build on a common pattern: write a source, derive an answer, and read that answer in JSX.

```jsx
import { render } from '@solidjs/web';

function HelloWorld() {
  return <div>Hello Solid World!</div>;
}

render(() => <HelloWorld />, document.getElementById('app'));
```
