# Conditional rendering

`Show` owns a conditional branch. Its `when` expression is reactive, and its fallback renders when that expression is false.

```jsx
<Show when={loggedIn()} fallback={<button onClick={toggle}>Log in</button>}>
  <button onClick={toggle}>Log out</button>
</Show>
```

When the condition changes, Solid creates or disposes the appropriate branch. Work owned by a removed branch is cleaned up. A plain ternary is useful for small values; `Show` makes a branch's lifetime explicit.

**Try it:** replace the two always-visible buttons with one `Show` and a fallback. Both buttons should still toggle the source signal.
