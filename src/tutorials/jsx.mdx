# JSX and DOM expressions

JSX describes elements and bindings. Lowercase tags create native DOM elements; capitalized tags call components. Curly braces insert JavaScript expressions.

```jsx
<div>Hello {name}!</div>
```

Reactive reads inside those expressions stay connected to their sources. A local variable can also hold a DOM subtree, such as the SVG in this exercise. Return a fragment (`<>...</>`) when several sibling nodes belong together.

**Try it:** add the provided SVG after the greeting and return both in a fragment. Native attributes follow HTML and SVG spelling: use `class`, `for`, `tabindex`, and `stroke-width`. Web JSX types and renderer helpers belong to `@solidjs/web`.
