Memo, effect, or root created inside an effect callback or its cleanup, where there is no ambient owner (throws).

## What you saw

- **Kind:** `lifecycle`
- **Severity:** `error` (broken behavior)

The console report opens with `[PRIMITIVE_IN_EFFECT_CALLBACK]` and the message, then an `in` line naming the owners that enclose the subject, root first, and an `at` line with the source location when the code was compiled with one.
In a captured artifact the same finding is an event with `code: "PRIMITIVE_IN_EFFECT_CALLBACK"`, `ownerPath`, and `loc`.
[Diagnostics](/reference/solid-js/diagnostics#read-a-report) explains each line.

## Why it fires

A memo, effect, or root was created without an owner inside an effect callback or its cleanup.
The effect phase has no ambient owner, so those computations cannot be disposed or held by a parent.

## How to fix it

Create them in the compute phase, or attach them to an existing owner with `runWithOwner`.
Creating a signal alone does not trigger this error.

## In tests

`captureArtifact` from `@solidjs/diagnostics` runs a scenario with the diagnostics channel open and returns the events it saw.
