Effect created without reactive owner.

## What you saw

- **Kind:** `lifecycle`
- **Severity:** `warn` (code that works but is structurally wrong or expensive)

The console report opens with `[NO_OWNER_EFFECT]` and the message, then an `in` line naming the owners that enclose the subject, root first, and an `at` line with the source location when the code was compiled with one.
In a captured artifact the same finding is an event with `code: "NO_OWNER_EFFECT"`, `ownerPath`, and `loc`.
[Diagnostics](/reference/solid-js/diagnostics#read-a-report) explains each line.

## Why it fires

An effect was created outside any reactive context (no root, no component).

## How to fix it

Create it under a component or `createRoot`, or use `runWithOwner` to attach it to an existing owner so it can be disposed.

## In tests

`captureArtifact` from `@solidjs/diagnostics` runs a scenario with the diagnostics channel open and returns the events it saw.
`expectNoDiagnostics(artifact)` fails while `NO_OWNER_EFFECT` is among them, with the events as evidence; after the fix, the code is gone from `artifact.diagnostics`.
