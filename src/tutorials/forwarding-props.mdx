# Forwarding props

A wrapper often consumes a few props and forwards everything else to a DOM element. `omit` creates a reactive view that excludes the consumed keys:

```js
const others = omit(props, 'greeting', 'name');
```

```jsx
<h3 {...others}>
  {props.greeting} {props.name}
</h3>
```

This preserves reactive getters without copying or destructuring them during setup. Spreading the remainder also avoids forwarding component-only props as native attributes.

**Try it:** use `omit` to forward the style prop to the heading. Keep `greeting` and `name` as direct reactive reads. Clicking **Set Name** should update the heading while retaining its color.
