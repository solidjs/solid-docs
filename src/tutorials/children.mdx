# Resolving children

Reading `props.children` can create child nodes. If you need to inspect and render those children, resolve them once through `children` so both operations share the same result.

```js
const resolved = children(() => props.children);
```

For imperative DOM work, compute the child elements and color in the tracking half of an effect. Apply the color in the second half. The solved code accepts either one resolved child or an array.

**Try it:** resolve the colored list's children and add a split effect that applies `props.color` to each element. Render the same resolved children afterward. **Set Color** should update all three items without creating a second set of DOM nodes.
