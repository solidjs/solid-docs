# Components create the graph

A component function sets up a part of the reactive graph and returns its view. Updating a signal normally reruns the relevant derivations and bindings, not that setup function.

Extracting a view into another component gives that view its own owned scope. When control flow removes it, its effects, derivations, and registered cleanup are disposed with it.

**Try it:** import the default export from `./nested` and render `<Nested />` below the heading. Keep the component's props object intact when reading reactive inputs; destructuring a reactive prop during setup would take a one-time snapshot. The composition section explores this in detail.
