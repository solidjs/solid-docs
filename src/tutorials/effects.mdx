# Compute, then apply

Use effects to synchronize with something outside the reactive graph: console output, DOM APIs, or an external subscription. Derive ordinary values with functions or memos instead.

A Solid 2 effect has separate tracking and apply functions:

```js
createEffect(count, (value) => console.log('The count is now', value));
```

The first function reads dependencies and returns the answer needed by the side effect. The second receives that answer and may return cleanup. Reads made only in apply do not become dependencies; no new reactive primitives should be created there.

**Try it:** add a split effect that logs `count`. Click the button and inspect the preview console. The JSX binding and the effect independently consume the same source.
