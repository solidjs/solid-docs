Renders an arbitrary custom or native component and forwards the other
props. JSX form of `dynamic()` — same primitive, picked at the JSX site.

> `<Dynamic>` is a JSX convenience wrapper. General application code should use `dynamic()` to create a reusable stable component reference.

## Import

```ts
import { Dynamic } from "@solidjs/web";
```

## Type signature

```ts
function Dynamic<T extends ValidComponent>(props: DynamicProps<T>): JSX.Element;
```

## Examples

```tsx
<Dynamic
	component={multiline() ? RichTextEditor : "input"}
	value={value()}
	onInput={onInput}
/>
```

## Related types

### `DynamicProps`

```ts
type DynamicProps<T extends ValidComponent, P = ComponentProps<T>> = {
	[K in keyof P]: P[K];
} & {
	component: T | null | undefined | false;
};
```
