Solid Router is the router published as `@solidjs/router`.
It is an optional package for Solid applications that need URL matching, navigation, nested layouts, or route-aware data loading.
Other routers can be used with Solid instead.

Solid Router 2 defines routes as configuration objects.
`createRouter` turns the route tree into a provider component, a typed path builder, and a URL matcher.
Components read the active routing session through primitives such as `useLocation`, `useParams`, and `useNavigate`.

## Start here

1. [Install and create a router](/routing/solid-router/setup) to mount a minimal application.
2. [Define routes](/routing/solid-router/route-definitions) with static, dynamic, optional, wildcard, lazy, or file-system-backed paths.
3. [Build nested routes and layouts](/routing/solid-router/nested-routes) with `children` and `props.children`.
4. [Navigate with typed paths](/routing/solid-router/navigation) through anchors, `Router.paths`, and routing primitives.
5. [Preload and mutate data](/routing/solid-router/data) with route preloads, `query`, and `action`.
6. [Connect server rendering and hydration](/routing/solid-router/server-rendering) when the application renders on the server or uses server functions.

## Package entries

- `@solidjs/router` contains the router factory, route and navigation primitives, history adapters, queries, and actions.
- `@solidjs/router/fs` converts a `file-routes` manifest into route definitions.
- `@solidjs/router/server` provides the single-flight data collector for a server-function handler.

Use the [Solid Router API reference](/reference/solid-router) for signatures and option details.
