# Initial readiness

A read of an unresolved async memo or lazy component needs a place to wait. `Loading` renders a fallback while that branch first becomes ready.

```jsx
<Loading fallback={<p>Loading...</p>}>
  <Greeting name="Jake" />
</Loading>
```

Place the boundary around the smallest useful region. Surrounding content can render immediately. Once a boundary has revealed, later pending updates normally retain useful settled content. To show the fallback again when a particular input changes, track that input in `on`:

```jsx
<Loading on={selectedId()} fallback={<p>Loading selection...</p>}>
  <Details />
</Loading>
```

**Try it:** wrap the delayed greeting in `Loading`. The heading should remain visible while the greeting's component code loads. The pending lesson compares retaining content with resetting a boundary.
