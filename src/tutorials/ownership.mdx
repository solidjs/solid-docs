# State lifetime

Reactive work belongs to an owner. Components, conditional branches, and list rows establish scopes that collect their computations and cleanup. When a scope is disposed, its owned work is disposed with it.

This matters when a branch starts a timer, observer, or subscription. Hiding a timer's text with CSS does not dispose that work. Removing its component with `Show` does.

**Try it:** toggle the timer component on and off. Add a cleanup function to its `onSettled` callback. Each new mount should start at zero and each removal should stop that instance's timer. Watch the console to verify that only the visible timer continues ticking.

Nested `createRoot` scopes are owned by their parent in Solid 2. You rarely need an extra root inside a component; its existing owner already provides the lifetime you need.
