# Conditional classes

Solid 2's `class` prop handles conditional classes directly. An object maps class names to conditions; an array combines strings and objects.

```jsx
<button class={['choice', { selected: current() === 'foo' }]}>foo</button>
```

This keeps static and conditional classes in one expression. The condition stays reactive and toggles the matching class when its source changes.

**Try it:** add a conditional `selected` class to each button. Clicking a choice should highlight that button and remove the highlight from the others. Use the `class` prop rather than the old separate class-list API.
