# Events and writes

Event handlers are a natural place to write sources. Use `event.currentTarget` to refer to the element whose handler is running, and read any needed values before an asynchronous pause.

```jsx
<input onInput={(event) => setName(event.currentTarget.value)} />
```

DOM event props use names such as `onInput`, `onChange`, and `onMouseMove`. Many common events are delegated by the renderer. State writes are batched automatically, so related setters in one event form one update.

**Try it:** attach `onMouseMove={handleMouseMove}` to the container. The provided handler records the pointer's `clientX` and `clientY` in the source object. Read the coordinates from the event; keep the changing position read in JSX.
