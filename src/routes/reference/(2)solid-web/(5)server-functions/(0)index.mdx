`@solidjs/web/server-functions` provides the runtime used by functions compiled with `"use server"`.
The package resolves to a browser transport in client builds and a dispatcher in server builds.
Shared declarations such as `GET`, `live`, `withMeta`, and `invoke` have matching types in both environments.

Start with the [server functions guide](/building-apps/server-functions) for application patterns.
Use the integration pages in this section when building a router, development tool, or custom server host.

## Declarations and calls

- [`GET()`](/reference/solid-web/server-functions/get) declares an HTTP read.
- [`live()`](/reference/solid-web/server-functions/live) declares a reconnecting value stream.
- [`invoke()`](/reference/solid-web/server-functions/invoke) supplies per-call Fetch options.
- [Metadata APIs](/reference/solid-web/server-functions/metadata) attach and inspect declaration metadata.

## Runtime configuration

- [`configureServerFunctionsClient()`](/reference/solid-web/server-functions/configure-client) configures the browser endpoint, codec, and request policy.
- [`enableRichArguments()`](/reference/solid-web/server-functions/rich-arguments) enables arguments that JSON cannot preserve.
- [Host configuration](/reference/solid-web/server-functions/host-configuration) documents the server dispatcher and policy hooks.
- [Invocation context](/reference/solid-web/server-functions/invocation-context) identifies the current server-function call.

## Integration protocols

- [Addressing](/reference/solid-web/server-functions/addressing) builds and parses server-function URLs.
- [Progressive enhancement](/reference/solid-web/server-functions/progressive-enhancement) handles requests made without the client runtime.
- [Single-flight data](/reference/solid-web/server-functions/single-flight) lets a router fold refreshed data into a mutation response.
- [Call observation](/reference/solid-web/server-functions/observe-calls) exposes cloned browser requests and responses to development tools.

The configuration hooks and wire decoders are integration-tier APIs.
Application code normally uses a generated reference, the response helpers in `@solidjs/web`, and an optional router data layer.

Server components and the `@solidjs/web/frames` transport remain experimental.
They are not part of the stable server-function reference.
