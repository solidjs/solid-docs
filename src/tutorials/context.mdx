# Providing state with context

Context gives descendants access to a value without passing it through each intermediate component. Create the context once, then create a fresh state instance inside its provider component.

```jsx
<CounterContext value={counter}>{props.children}</CounterContext>
```

The context itself is the provider in Solid 2. `useContext(CounterContext)` retrieves the nearest value. A context created without a default throws if a consumer has no provider, which catches wiring mistakes early.

**Try it:** wrap the app in `CounterProvider` and read its value in the nested counter. The plus and minus buttons should update the shared count. The provider uses a function-form signal to derive its initial value from its reactive `count` prop.
